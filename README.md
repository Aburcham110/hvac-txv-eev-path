# HVAC TXV / EEV Path (Educational)

Python **stdlib-only** ranked diagnostic path for TXV/EEV issues with optional SH/SC context.

> **Educational only — OEM targets vary.**

## Quick start

```bash
cd hvac-txv-eev-path
python3 txv_eev_path.py --valve txv --symptom hunting --sh 18 --sc 10
python3 txv_eev_path.py --valve eev --symptom high-sh --sh 25
python3 txv_eev_path.py -i
```
